知识卡
· 分式 A/B 中 B 含字母，这是它与分数的本质区别
· 分式有意义 ⇔ 分母 B ≠ 0（先看分母！）
· 分式值为 0 ⇔ 分子 A = 0 且 分母 B ≠ 0（两个条件缺一不可）
· 基本性质：分子分母同乘(除)同一个不为 0 的整式，值不变——约分、通分的依据
