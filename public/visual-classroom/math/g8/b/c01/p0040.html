① 定义与几何模型（蓝）

√a (a ≥ 0) 叫做二次根式，其中 "√" 是二次根号。
教材原生模型：正方形面积为 S，则边长 = √S。
如 S=9 → 边长 √9=3；S=2 → 边长 √2。面积决定边长，这就是二次根式的来源。

② 双重非负性（绿）

a ≥ 0 且 √a ≥ 0
① 被开方数非负：a<0 时 √a 无意义；② 运算结果非负：根号出来的是算术平方根。
几何解释：正方形的面积不能为负，边长也不能为负。

③ 性质 1（紫）

(√a)² = a  (a ≥ 0)
先开方、再平方 → 还原回本身。几何：边长 √a 再自乘一次，恰好得到面积 a。例：(√5)² = 5，(√9)² = 9。

④ 性质 2 与易错警示（红）

√(a²) = |a|  (a 取任意实数)
先平方、再开方 → 结果等于绝对值。
⚠ 易错警示：当 a = −3 时，√((−3)²) = √9 = 3，而 3 ≠ −3！
所以 √(a²) = |a|，而不是 a。只有 a≥0 时才等于 a 本身。

✏️ 例题原型：二次根式有意义的条件

x 为何值时 √(4−3x) 有意义？
条件：被开方数 4−3x ≥ 0 ⇔ x ≤ 4/3 ≈ 1.33
（√a）² = a a≥0 ｜ 先开后平 → 等于本身
√(a²) = |a| a 取任意数 ｜ 先平后开 → 等于绝对值
口诀：先开后平等于本身，先平后开等于绝对值
