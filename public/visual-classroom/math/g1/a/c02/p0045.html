📝 推导过程

📚 知识点总结 一表梳理，考前速记

基本不等式：$\sqrt{ab}\le\dfrac{a+b}{2}\quad(a>0,\ b>0)$，当且仅当 $a=b$ 时取等号。

✅ 使用条件

一正

  • 各项必须为正数（$a>0,\ b>0$）
  • 出现负数先变号 / 提负号再使用
  • $\sqrt{ab}$ 要求 $ab\ge 0$，否则无意义

二定

  • 求和的最小值 → 需 $ab$ 为定值
  • 求积的最大值 → 需 $a+b$ 为定值
  • 不是定值要先配凑出定值（拆项、凑系数）

三相等

  • 等号成立条件 $a=b$ 必须能取到
  • 要检验 $a=b$ 是否在定义域内
  • 多次使用时，各次等号条件须一致

🔁 常用变形

变形形式说明 / 用途
$a+b\ \ge\ 2\sqrt{ab}$积为定值时，和有最小值 $2\sqrt{ab}$（"积定和最小"）
$ab\ \le\ \left(\dfrac{a+b}{2}\right)^{2}$和为定值时，积有最大值 $\left(\frac{a+b}{2}\right)^{2}$（"和定积最大"）
$a^{2}+b^{2}\ \ge\ 2ab\ (a,b\in\mathbb R)$不要求正数；配方、比较大小、求最值的基础
$\dfrac{2}{\frac1a+\frac1b}\ \le\ \sqrt{ab}\ \le\ \dfrac{a+b}{2}\ \le\ \sqrt{\dfrac{a^{2}+b^{2}}{2}}$ 均值链：调和平均 ≤ 几何平均 ≤ 算术平均 ≤ 平方平均

⚠️ 常见失分点：忘记验证"正数"前提；凑不出定值就下结论；等号取不到却写出最值。
