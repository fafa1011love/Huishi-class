正弦函数 y = sin x 的图象与性质

由单位圆上点的纵坐标随角的变化可以得到正弦曲线；图中标注了 (0,0)、(π/2,1)、(π,0)、(3π/2,−1)、(2π,0) 等关键点的坐标。

定义域

R（全体实数）

值域

[−1, 1]，有最大值 1、最小值 −1

周期性

最小正周期 T = 2π

奇偶性

奇函数：sin(−x) = −sin x，图象关于原点对称

单调性

增区间 [−π/2+2kπ, π/2+2kπ]

减区间 [π/2+2kπ, 3π/2+2kπ]（k∈Z）

最值点

y=1 时 x = π/2 + 2kπ

y=−1 时 x = −π/2 + 2kπ

对称性

对称轴 x = π/2 + kπ

对称中心 (kπ, 0)，k∈Z

零点

x = kπ，k∈Z

余弦函数 y = cos x 的图象与性质

余弦曲线可由正弦曲线向左平移 π/2 个单位得到：cos x = sin(x + π/2)。图中标注了 (0,1)、(π/2,0)、(π,−1)、(3π/2,0)、(2π,1) 等关键点的坐标。

定义域

R（全体实数）

值域

[−1, 1]，有最大值 1、最小值 −1

周期性

最小正周期 T = 2π

奇偶性

偶函数：cos(−x) = cos x，图象关于 y 轴对称

单调性

增区间 [−π+2kπ, 2kπ]

减区间 [2kπ, π+2kπ]（k∈Z）

最值点

y=1 时 x = 2kπ

y=−1 时 x = π + 2kπ

对称性

对称轴 x = kπ

对称中心 (π/2 + kπ, 0)，k∈Z

零点

x = π/2 + kπ，k∈Z

正切函数 y = tan x 的图象与性质

正切曲线由无数支组成，被渐近线 x = π/2 + kπ 隔开；每支都是上升的，但在整个定义域上不是增函数。

定义域

{ x | x ≠ π/2 + kπ, k∈Z }

值域

R（全体实数），无最大、最小值

周期性

最小正周期 T = π

奇偶性

奇函数：tan(−x) = −tan x，图象关于原点对称

单调性

在开区间 (−π/2+kπ, π/2+kπ) 上单调递增

渐近线

x = π/2 + kπ，k∈Z

对称性

无对称轴；对称中心 (kπ/2, 0)，k∈Z

零点

x = kπ，k∈Z；且 tan(π/4+kπ) = 1
