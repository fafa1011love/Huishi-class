知识点总结

  • 幂函数的概念：一般地，函数 y = xα 叫做幂函数，其中 x 是自变量，α 是常数。注意与指数函数 y = ax 区分：幂函数底数是变量、指数是常数；指数函数底数是常数、指数是变量。
  • 五个重点函数：教材重点研究 y = x、y = x²、y = x³、y = x1/2、y = x−1 这五个幂函数（可用上方"常用指数"按钮逐一切换，再点"钉住当前曲线"把它们同时画出来对比）。
  • 图像与性质（第一象限）：
    • ① 所有幂函数的图象都过定点 (1, 1)；
    • ② 当 α > 0 时，图象过原点，且在 (0, +∞) 上单调递增；
    • ③ 当 α < 0 时，图象不过原点，在 (0, +∞) 上单调递减，且向右、向上无限接近 x 轴和 y 轴，但永不相交；
    • ④ 图象永远只出现在第一象限（奇、偶函数会延伸到第二或第三象限），不会出现在第四象限。
  • 定义域随 α 而不同：α 为正整数时定义域为 R；α 为分数时需保证被开方数有意义（如 y=x1/2 要求 x≥0）；α 为负数或 0 时 x ≠ 0。
  • 奇偶性的判断：先把 α 化为既约分数 p/q（q>0）：若 q 为偶数，定义域不关于原点对称，是非奇非偶函数；若 q 为奇数，则 p 为奇数时是奇函数、p 为偶数时是偶函数。
