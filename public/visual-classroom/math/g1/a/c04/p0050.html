知识点总结

  • 对数的概念：一般地，如果 ab = N（a > 0，且 a ≠ 1），那么数 b 叫做以 a 为底 N 的对数，记作 b = logaN，其中 a 叫做底数，N 叫做真数。
    • ① 指数式与对数式互化：ab = N ⇔ logaN = b；
    • ② 负数和 0 没有对数，真数必须满足 N > 0；
    • ③ loga1 = 0，logaa = 1；对数恒等式 alogaN = N；
    • ④ 常用对数 lg N = log10N，自然对数 ln N = logeN（e = 2.71828…）。
  • 对数的运算性质：设 a > 0，a ≠ 1，M > 0，N > 0，则
    • ① loga(M·N) = logaM + logaN；
    • ② loga(M/N) = logaM − logaN；
    • ③ logaMn = n·logaM（n ∈ R）。
    换底公式：logab = logcb / logca（c > 0，c ≠ 1），特别地 logab = lg b / lg a = ln b / ln a，且 logab · logba = 1。 注意 loga(M + N) 不能拆成两对数之和。
  • 对数函数的概念：一般地，函数 y = logax（a > 0，且 a ≠ 1）叫做对数函数，其中 x 是自变量。

    识别要点：

    • ① 系数必须是 1；
    • ② 底数 a 是大于 0 且不等于 1 的常数；
    • ③ 自变量 x 出现在真数位置，且必须 x > 0。
    它来自指数式 y = ax 的反解：x = logay，习惯上写成 y = logax。
  • 图像与性质：教材重点研究 y = log2x 与 y = log1/2x，由此归纳出 a > 1 与 0 < a < 1 两类图像。
    项目a > 1（如 y = log2x）0 < a < 1（如 y = log1/2x）
    定义域(0, +∞)
    值域R
    定点图象都过定点 (1, 0)
    单调性在 (0, +∞) 上单调递增在 (0, +∞) 上单调递减
    函数值分布x > 1 时 y > 0；0 < x < 1 时 y < 0x > 1 时 y < 0；0 < x < 1 时 y > 0
    奇偶性非奇非偶

    两类图象都只分布在第一、四象限。
  • 两类对称关系：
    • ① y = logax 与 y = log1/ax = −logax 的图象关于 x 轴对称；
    • ② y = logax 与 y = ax 互为反函数，图象关于直线 y = x 对称。
  • 底数大小与图像位置的关系：
    • ① 所有图象都过同一定点 (1, 0)；
    • ② 作直线 y = 1，与图象交点的横坐标恰好等于底数 a（因为 logaa = 1）；
    • ③ 在同一 x > 0 且 x ≠ 1 处：a > 1 时，底数越大，图象越靠近 x 轴；0 < a < 1 时，底数越大，图象越远离 x 轴。
  • 简单应用：对数增长的特点是越来越慢。当 a > 1、k > 0 时，总存在 x0，使得 x > x0 后恒有 logax < kx < ax；实际问题中常用对数模型描述 pH 值、地震震级、声音分贝等"压缩尺度"的量。
