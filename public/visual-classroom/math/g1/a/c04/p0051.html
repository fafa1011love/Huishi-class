知识点总结

  • 指数函数的概念：一般地，函数 y = ax（a > 0，且 a ≠ 1）叫做指数函数，其中 x 是自变量，定义域为 R。

    识别要点：

    • ① 系数必须是 1；
    • ② 底数 a 是大于 0 且不等于 1 的常数；
    • ③ 自变量 x 出现在指数位置。
    注意与幂函数 y = xα 区分：指数函数底数是常数、指数是变量；幂函数底数是变量、指数是常数。
  • 图像与性质：教材重点研究 y = 2x 与 y = (1/2)x，由此归纳出 a > 1 与 0 < a < 1 两类图像（点上方"一次显示全部"可把六条常用曲线画在一起对比）。
    项目a > 1（如 y = 2x）0 < a < 1（如 y = (1/2)x）
    定义域R
    值域(0, +∞)，即 ax > 0 恒成立
    定点图象都过定点 (0, 1)，即 a0 = 1
    单调性在 R 上单调递增在 R 上单调递减
    函数值分布x > 0 时 y > 1；x < 0 时 0 < y < 1x < 0 时 y > 1；x > 0 时 0 < y < 1
    奇偶性非奇非偶
    渐近线以 x 轴（y = 0）为渐近线：图象无限接近 x 轴，但永不相交
  • 两类指数函数的对称关系：y = ax 与 y = (1/a)x = a−x 的图象关于 y 轴对称。
  • 底数大小与图像位置的关系：
    • ① a > 1 时，底数越大，图象越靠近 y 轴；
    • ② 0 < a < 1 时，底数越大，图象越远离 y 轴；
    • ③ 所有图象都交于同一定点 (0, 1)。
  • 实数指数幂的运算性质：设 a > 0，b > 0，r, s ∈ R，则
    • ① ar · as = ar+s；
    • ② (ar)s = ars；
    • ③ (ab)r = ar br；
    • ④ ar ÷ as = ar−s。
  • 分数指数幂与根式：am/n = n√am（a > 0，m, n ∈ N*，n > 1）；a−m/n = 1 / am/n。0 的正分数指数幂等于 0，0 的负分数指数幂无意义。
  • 简单应用：形如 y = k · ax（k > 0，a > 0，a ≠ 1）的模型可描述指数增长（a > 1，如细胞分裂、复利、人口增长）与指数衰减（0 < a < 1，如放射性元素衰变、药物代谢）。
