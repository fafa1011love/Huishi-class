三个估计值怎么算（考试写法）

众数估计：最高矩形的底边中点。
x众 = ( l底 + r底 ) / 2
中位数估计：把直方图面积左右平分的竖线横坐标（设中位数落在底边为 l、宽为 d、高为 f 的组内，该组左侧累积频数为 F，样本容量 n）：
x中 = l + ( n/2 − F ) / f × d
平均数估计：每个组用组中值代表，求加权平均：
x平 = Σ (组中值 × 频数) / n
