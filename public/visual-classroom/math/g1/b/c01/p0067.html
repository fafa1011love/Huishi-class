教材原话（6.3.1 平面向量基本定理）：如果 e₁、e₂ 是同一平面内的两个不共线向量，那么对于这一平面内的任一向量 a，有且只有一对实数 λ₁、λ₂，使 a = λ₁e₁ + λ₂e₂。
代数上，λ₁、λ₂ 是方程组 x·e₁ + y·e₂ = a 的解；由克拉默法则，det(e₁,e₂) ≠ 0 时解存在且唯一： λ₁ = (a×e₂)/(e₁×e₂)，λ₂ = (e₁×a)/(e₁×e₂)。
图中两条分量 λ₁e₁、λ₂e₂ 都从原点 O 画出，就是平行四边形的两条邻边；两条虚线把平行四边形补完整，a 与 O 是它的对角顶点。 分量箭头指向与基底相反时，表示对应的 λ 为负数（这正是定理允许的），并非分解出错。
拖动 e₁、e₂ 使它们趋于共线，可以观察 det → 0 时 λ₁、λ₂ 剧烈变化乃至分解失效——这正是「不共线」条件不可缺的原因。
