原理实验原理

F₁ · L₁ = F₂ · L₂
  • 杠杆平衡：静止或匀速转动，此时两侧力矩相等、方向相反。
  • 力臂 L 是支点到力的作用线的垂直距离，不是杆身长度。
  • 动力斜拉时 L₁ = d₁·sinθ：θ 越小力臂越小；θ=0° 时 L₁=0，再大的力也扳不动。
  • 省力必费距离：L₁ 越大，所需 F₁ 越小。
杠杆的三类（由 L₁ 与 L₂ 决定）
  • 省力杠杆：L₁ > L₂，撬棍、钳子、起子。
  • 费力杠杆：L₁ < L₂，镊子、钓鱼竿、筷子。
  • 等臂杠杆：L₁ = L₂，天平、定滑轮。

知识知识点梳理

一、实验目的与原理

  • 目的：探究杠杆平衡时，动力、动力臂与阻力、阻力臂之间的定量关系。
  • 原理：杠杆静止（或匀速转动）即处于平衡状态，此时两侧力矩大小相等、方向相反。

二、杠杆五要素

  • 支点 O：杠杆绕其转动的固定点（本实验为支架刀口）。
  • 动力 F₁：使杠杆转动的力（右侧，由弹簧测力计斜拉提供）。
  • 阻力 F₂：阻碍杠杆转动的力（左侧，钩码重力）。
  • 动力臂 L₁：支点到动力作用线的垂直距离。
  • 阻力臂 L₂：支点到阻力作用线的垂直距离。
易错点（考试高频）：力臂是“支点到力的作用线的垂直距离”，绝不是杠杆的杆身长度！作用线是一条直线，力臂一定是从支点向该直线所作的垂线段。

三、杠杆平衡条件

F₁ · L₁ = F₂ · L₂
推导：以支点 O 为转轴，平衡时顺时针力矩 = 逆时针力矩。 左侧阻力产生顺时针力矩 M₂ = F₂·L₂，右侧动力产生逆时针力矩 M₁ = F₁·L₁， 故 F₁L₁ = F₂L₂。当动力斜拉时，L₁ = d₁·sinθ（θ 为动力与杠杆夹角），可见 θ 越小力臂越小。
  • θ = 0° 时动力沿杠杆方向，L₁ = 0，无论动力多大都无法使杠杆平衡——这正是“力臂为零则无力矩”。
  • 省力必然费距离：L₁ 越大（动力作用点越远），所需 F₁ 越小。

四、实验步骤（探究杠杆平衡条件）

  • ① 调节杠杆两端平衡螺母，使杠杆在水平位置平衡（便于直接从刻度读出力臂）。
  • ② 左侧挂 n₂ 枚钩码，记录阻力 F₂ 与阻力臂 L₂。
  • ③ 右侧用弹簧测力计斜拉，使杠杆再次水平平衡，记录 F₁、L₁（及夹角 θ）。
  • ④ 改变钩码数量或位置，多次实验，将数据填入记录表。
  • ⑤ 比较各组 F₁L₁ 与 F₂L₂，归纳结论。

五、杠杆的分类（由 L₁ 与 L₂ 决定）

  • 省力杠杆：L₁ > L₂，动力 < 阻力（费距离）。例：撬棍、钳子、起子。
  • 费力杠杆：L₁ < L₂，动力 > 阻力（省距离）。例：镊子、钓鱼竿、筷子。
  • 等臂杠杆：L₁ = L₂，动力 = 阻力。例：天平、定滑轮。
判定口诀：
看力臂：谁离支点远，谁就“占便宜”。
动力臂长 → 省力；阻力臂长 → 费力。
平衡的本质是 力矩相等，而非力相等。
