知识点

1定滑轮与动滑轮

  • 定滑轮：轴固定不动；实质是等臂杠杆 → 不省力，但能改变力的方向。
  • 动滑轮：轴随物体一起移动；实质是动力臂为阻力臂 2 倍的杠杆 → 省一半力，但不能改变力的方向。
  • 滑轮组＝定滑轮＋动滑轮组合，兼顾省力与改向。

2省力规律与公式

  • 拉力：F = (G + G动) / n（忽略绳重与摩擦）
  • 距离：s = n × h（绳端移动是物体上升的 n 倍）
  • 效率：η = G / (G + G动)
  • 结论：n 越大越省力，但省力必然费距离，使用任何机械都不省功。

3如何正确数 n

  • 只数直接向上拉住动滑轮（或重物）的绳段——图中橙色高亮的就是 n 段。
  • 绕在定滑轮上的绳段不算，它只起改变方向的作用。
  • 口诀「奇动偶定」：n 为奇数时绳的固定端系在动滑轮，n 为偶数时系在定滑轮（可反过来检查绕线画得对不对）。
  • 技巧：把「动滑轮＋重物」当作整体隔离出来，数有几段绳向上拉它。

4方向规律与常见误区

  • 能否改变力的方向由绕线决定：本演示两种绕法自由端都向下——向下拉、物体上升，即改变了方向（可借助体重，操作方便）。
  • 误区一：把定滑轮上的绳段也数进 n → n 偏大、算出的拉力偏小。
  • 误区二：认为「省力就省功」→ 实际 F 变小但 s 变大，功不变。
  • 误区三：忽略动滑轮自重 → 实际 F=(G+G动)/n，比 G/n 大。
