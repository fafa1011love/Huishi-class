核心规律与三种情形

① 阻力方向铁律：空气阻力方向 始终与物体运动方向相反（即与速度 v 反向）。
② 上升阶段：重力(↓) 与 阻力(↓) 同向 → 合力向下且更大，减速更快。
③ 下落阶段：重力(↓) 与 阻力(↑) 反向 → 合力 = G − f，向下（通常）。
④ 最高点：v ≈ 0 → 阻力 ≈ 0，此刻小球只受重力。
⑤ 收尾速度：下落中阻力随 v 增大；当 f = G 时合力为 0、加速度为 0，此后匀速下落，vt = mg/k。
G = m·g （恒向下）
f = −k·v （负号 = 与速度反向）
F合 = G + f = −(m·g + k·v)

仿真模型与数值推导

本仿真取 质量 m = 1 kg，阻力采用线性模型 f = k·v（大小与速率成正比、方向恒与速度反向），对运动方程做实时数值积分：
加速度 a = F合/m = −(g + k·v/m)
上升时 v > 0 → a 向下且偏大；下落时 v < 0 → 阻力向上抵消部分重力。
说明：真实空气阻力多为 f ∝ v（低速）或 f ∝ v²（高速），此处为便于教学采用线性近似。
a = −(g + (k/m)·v)
v(t+Δt) = v(t) + a·Δt
s(t+Δt) = s(t) + v·Δt （Δt 为实时步长）

实验原理与结论（课本原文）

大量实验研究表明：
同一直线上的两个力，如果方向相同，合力的大小等于这两个力的大小之和，合力的方向与这两个力的方向相同；
如果方向相反，合力的大小等于这两个力的大小之差，合力的方向与较大的力方向一致。
应用：行驶在平直轨道上的列车，若牵引力与阻力大小相等，则合力为 0、二力平衡，列车做匀速直线运动；若牵引力小于阻力，合力不为 0、方向与前进方向相反，列车逐渐慢下来。

为什么要拉到同一个 O 点？（等效替代）

橡皮筋伸长量相同 ⟹ 橡皮筋弹力相同 ⟹ 对小圆环的作用效果相同。
因此「两个测力计共同作用」与「一个测力计单独作用」能把圆环拉到同一位置 O，说明这一个力的作用效果与那两个力共同作用的效果完全等效，这一个力就是它们的合力。
本仿真把这一点量化了：取橡皮筋劲度 k = 2 N/cm，则 Δx = F合/k —— 无论用两个力还是一个力，只要圆环停在同一 O 点，Δx 就相同，可直接读出 F合 并验证合成规则。
多次改变 F₁、F₂ 重复实验，结论才具有普遍性。
Δx = F合 / k （k = 2 N/cm）
同向：F合 = F₁ + F₂
反向：F合 = |F₁ − F₂|

实验原理与结论（平行四边形定则）

如果用来表示两个力 F₁ 和 F₂ 的线段为邻边作平行四边形，那么合力 F 的大小和方向可以用这两个邻边之间的对角线表示，这叫做力的平行四边形定则。
它是所有矢量合成的普遍法则，既适用于共点力，也适用于互成任意角度的两个力。
F合 = F₁ + F₂ （矢量相加）
大小：|F合| = √(F₁² + F₂² + 2F₁F₂·cosθ)
方向：与 F₁ 夹角 α = arctan( F₂·sinθ / (F₁ + F₂·cosθ) )

为什么要拉到同一个 O 点？（等效替代）

橡皮筋伸长量相同 ⟹ 橡皮筋弹力相同 ⟹ 对小圆环的作用效果相同。
因此「两个测力计共同作用」与「一个测力计单独作用」能把圆环拉到同一位置 O，说明这一个力的作用效果与那两个力共同作用的效果完全等效，这一个力就是它们的合力。
本仿真用平行四边形直观显示：以 F₁、F₂ 为邻边，对角线即合力 F合；步骤②读出的单力示数应与之吻合。
Δx = F合 / k （k = 2 N/cm）
合力方向 = 平行四边形对角线方向
