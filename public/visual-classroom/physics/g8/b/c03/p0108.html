一、核心公式

物体在液体中只受两个力：竖直向上的浮力和竖直向下的重力。浮沉取决于二者的合力方向。

F浮 = ρ液 · g · V排
阿基米德原理：浮力等于物体排开液体的重力
G = m · g = ρ物 · g · V物
重力由物体自身质量和密度决定
ρ：密度（kg/m³）　V：体积（m³）　g ≈ 9.8 N/kg

化简比较：两式都含 g，约去后只需比较 ρ液·V排 与 ρ物·V物。
当物体完全浸没时 V排 = V物，进一步约去 V，判定就变成纯粹的密度比较：

ρ物 < ρ液 → 上浮　|　ρ物 = ρ液 → 悬浮　|　ρ物 > ρ液 → 下沉

这就是本 Demo 中右侧实时显示的「物体密度 vs 液体密度」为什么能预判结果的原因。

二、浮沉条件判定表

下表按「完全浸没时」的受力关系分类——这是判定和计算的标准前提。

浸没时受力合力运动最终状态密度关系
F浮 > G向上上浮漂浮于液面
（F浮 = G）		ρ物 < ρ液
F浮 = G为零静止悬浮
（可停在任意深度）		ρ物 = ρ液
F浮 < G向下下沉沉底
（F浮 + N = G）		ρ物 > ρ液
易错点：「漂浮」和「悬浮」都满足 F浮 = G，但漂浮时物体部分露出液面（V排 < V物，ρ物 < ρ液）；悬浮时物体完全浸没（V排 = V物，ρ物 = ρ液）。二者受力相同但 V排 不同，必须区分。

三、浮力从哪来？——压强差的解释

浮力不是凭空产生的。液体内部压强随深度增加（p = ρ液gh），因此同一物体下表面所处的深度更大、受到的向上的压强更强，而上表面受到的向下压强较弱。这个压强差乘以受力面积，就是浮力。

图：上下表面压强差产生竖直向上的合力 —— 这就是浮力
F浮 = F向上 − F向下 = p₂S − p₁S = ρ液g(h₂ − h₁)S = ρ液gV排
h₂ > h₁，故 p₂ > p₁，合力竖直向上

侧面压力两两平衡、合力为零，所以只有上下表面的压强差留下了净效果。这也解释了：物体一旦沉到底部与容器底紧密贴合（底部无水），向上的压力消失，浮力会急剧减小甚至为零。

四、为什么会这样？——实验现象成因

Q1：为什么上浮到液面后会停在某个位置漂浮？
物体露出液面后，浸入的体积 V排 变小，由 F浮 = ρ液gV排 可知浮力随之减小。当 V排 减小到刚好让 F浮 = G 时，合力为零，物体静止漂浮。所以漂浮时浸入比例满足：V排/V物 = ρ物/ρ液。本 Demo 中可以看到物体一半左右露出水面正是这个比例。
Q2：为什么悬浮的物体能停在任意深度？
因为 F浮 = ρ液gV排 中不含深度 h（液体难压缩、ρ液 各处相同）。只要完全浸没且 ρ物 = ρ液，在任何深度都有 F浮 = G，合力恒为零。拖动 Demo 中的悬浮物体到其他深度再松手，它会停在原地不动——这是悬浮最典型的现象。
Q3：同一物体为什么在淡水中下沉、在盐水中却浮起来？
物体没变（V物、G 不变），但ρ液 变大了，于是完全浸没时的浮力 ρ液gV排 变大。当 ρ液 超过 ρ物 时，F浮 > G，物体就上浮了。点击「淡水→加盐」按钮即可复现这个经典实验：改变液体密度，而不是改变物体。
Q4：沉底后物体静止，此时 F浮 还小于 G 吗？
是的。此时物体受三个力：向上的浮力 F浮、容器底部向上的支持力 N、向下的重力 G，满足 F浮 + N = G。Demo 会在这种情况下显示支持力 N 的数值，可以看到容器底替液体"分担"了一部分重力。
