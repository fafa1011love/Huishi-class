10.4　电容器的电容

人教版《物理》必修第三册 · 第十章 静电场中的能量 · 教材 P38–P43 ｜ 覆盖知识点：充电与放电、C＝Q/U、平行板电容的决定式、接电源与断开电源两类动态分析
模块 1

电容器的充电与放电

RC 回路动画＋i–t 曲线
先想一想：充电刚开始的瞬间电流最大还是最小？电阻 R 变大，充满电要更久还是更快？
观察要点：充电时电流由 U₀/R 开始按指数衰减到 0，极板电荷越积越多、UC 趋于 U₀；放电时电流反向、大小同样按指数衰减。τ＝RC 越大，衰减越慢。
模块 2

电容 C＝Q/U

Q–U 数据图象
先想一想：把电压 U 加倍，极板上的电荷 Q 会怎样？Q/U 这个比值变不变？
观察要点：Q–U 是过原点的直线，斜率就是电容 C；换一个电容器，只是斜率变了，同一条线上的 Q/U 始终不变 —— C 由电容器本身决定。
模块 3

平行板电容的决定因素

动态分析交互
先想一想：充电后断开电源，再把两板拉远（d 变大），静电计张角会变大还是变小？先预测再验证。
观察要点：C＝εrS/(4πkd) —— d 越大 C 越小、S 与 εr 越大 C 越大。断开电源后 Q 不变，拉大 d 使 C 变小，于是 U＝Q/C 升高、静电计张角变大，而板间 E＝U/d＝4πkQ/(εrS) 保持不变。
