13.1　磁场　磁感线

人教版《物理》必修第三册 · 第十三章 电磁感应与电磁波初步 · 教材 P104–P108 ｜ 覆盖知识点：磁场与磁感线（闭合曲线、外部 N→S、疏密表强弱）、安培定则（右手螺旋定则）判断电流的磁场方向、地磁场与磁偏角
模块 1

磁感线：几种典型磁场的分布

交互仿真 · 可拖动小磁针
先想一想：磁感线是从 N 极出发、到 S 极就结束了吗？把小磁针拖到磁铁内部和外部各试一次，看它的 N 极指向哪儿。
观察要点：磁感线是闭合曲线——磁体外部由 N 极出来、回到 S 极，内部则由 S 极回到 N 极；磁感线越密的地方磁场越强；小磁针 N 极的指向就是该点的磁场方向（可拖着它到处走）。直导线、环形电流、螺线管的磁场都可以用安培定则判断方向。
模块 2

安培定则（右手螺旋定则）

交互仿真 · 右手示意
先想一想：把直导线里的电流方向反过来，它周围的磁感线是变疏了，还是绕向反了？先猜，再点按钮验证。
观察要点：直导线——拇指指向电流，四指环绕方向就是磁感线方向（电流反向，绕向随之反向）；螺线管——四指沿电流环绕，拇指指向螺线管的 N 极（内部磁感线由 S→N）。电流一反向，两端 N、S 立刻对调。
模块 3

地磁场：磁针为什么指北

示意图 · 观察点可切换
先想一想：指南针指的"北"，是地理北极吗？在赤道和在我国，磁针是水平的还是一头向下扎的？
观察要点：地磁轴与自转轴不重合（约差 11.5°），这就是磁偏角的由来（我国大部分地区约 2°～6°，各地不同）。磁针 N 极指北，是因为地理北极附近其实是地磁 S 极；磁针并非水平——北半球磁针北端向下倾斜，纬度越高倾角越大（赤道约 0°，我国约 55°，极区接近 90°）。面板中的磁偏角是偶极模型值，实际磁场更复杂、各地不同。
