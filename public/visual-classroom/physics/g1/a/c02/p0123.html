点迹疏密 → 位移数据 → 瞬时速度 → 加速度（逐差法）

1实验装置与运动过程

t = 0.00 s x = 0.0 cm v = 0.00 m/s 已打计数点 1 个 打点周期 T₀ = 0.02 s

木板一端垫高，小车由静止释放做匀加速直线运动。纸带穿过打点计时器随小车一起运动，计时器每隔 0.02 s 打一个点。

2展开的纸带 —— 点迹疏密反映速度

纸带从左向右依次是先打到后打的点。相邻计数点（每 5 个间隔取一个，T = 0.1 s）间距 x₁…x₆ 越来越大，说明相等时间内位移变大 → 速度变大。

相邻间距之差 Δx 是否相等，请看下方数据表。

3数据处理：求瞬时速度

vn = (xn + xn+1) / 2T   （某段时间内的平均速度 = 中间时刻的瞬时速度）

v–t 图像是一条倾斜直线：斜率 = 加速度 a，纵轴截距 = 初速度 v₀。这正说明小车做匀变速直线运动。

4逐差法求加速度

a = [(x₄+x₅+x₆) − (x₁+x₂+x₃)] / 9T²
点击“释放小车”完成测量后，这里给出加速度结果。

原理：相邻相等时间内的位移差恒定，Δx = xn+1 − xn = aT²。把 6 段位移分成前后两组对应相减，可让每一段数据都参与运算；若只算 x₂−x₁、x₃−x₂…再平均，中间项会全部抵消，等于只用了首尾两段，误差更大。

5知识要点

匀变速直线运动

沿直线运动，且加速度保持不变——任意相等时间内速度的变化量都相同。

a = (vt − v0)/t = 恒量
vt = v0 + at
x = v0t + ½at²
vt² − v0² = 2ax

器材清单

  • 长木板轨道（一端垫高）
  • 小车
  • 打点计时器（电磁式 4~6 V 交流电 / 电火花式 220 V）
  • 纸带（穿过限位孔，固定在小车尾部）
  • 刻度尺、复写纸、低压电源、导线

两个关键推论

  • 中间时刻速度：vn = (xn+xn+1)/2T
  • 连续相等时间位移差：Δx = aT²（推广 xm−xn = (m−n)aT²）
