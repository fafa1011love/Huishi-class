光电门读数 d/Δt 是平均速度

测量方法与误差说明

光电门测出的是挡光过程的平均速度 v̄ = d/Δt，它等于挡光中间时刻的瞬时速度，而不严格等于中间位置的瞬时速度。

挡光片越窄 d 越小越准；在最低点（切向加速度 a_t = g·sinθ = 0）测量偏差最小。

二阶修正：v² ≈ v̄² + a_t²d²/12，或 v ≈ v̄ + a_t²d²/(24 v̄³)。本 Demo 用前者修正 v²–h 图。

竖直弹簧振子的“等价技巧”

以平衡位置为原点的简化处理（技巧，不替代标准表达）

竖直方向受重力与弹力：合力 F = −k(u − mg/k)，u 为相对自然长度的伸长量。

令 ξ = u − mg/k（相对平衡位置的位移），则 F = −kξ，运动仍是简谐，ω = √(k/m)。

此时可写 E_机 = ½mv² + ½kξ² + 常数，便于解题；但标准表达仍是 ½mv² + ½kx² + mgh，两者只差一个常量。

机械能：系统的状态量 概念

机械能是动能与势能的总和，描述物体（系统）在某一状态下的“机械运动本领”。

功能关系的分工 概念

重力（弹力）做功只在系统内部把势能换成动能；除重力（弹力）以外的其他力做功才改变机械能。

守恒条件：只有重力（弹力）做功 概念

守恒的判据是 W_其他 = 0（其他力不做功或做功之和为零），而不是“只受重力”。

系统性：势能属于“系统” 概念

重力势能属于物体与地球组成的系统，弹性势能属于弹簧与物体组成的系统，守恒是对系统而言。

参考面的相对性与不变量 概念

换零势能面时 E_p 与 E_机 整体加减同一常数 mgΔh_ref，两状态间的 ΔE 与守恒结论不变。

等高往返：守恒的直观表现 概念

无阻力时摆球总能回到与释放点等高的另一侧，这是 E_机 恒定的几何表现。

内能与摩擦生热 Q 概念

摩擦力做功的一部分转化为内能，一对滑动摩擦力做的总功才等于系统增加的内能。

机械能守恒是能量守恒的特例 概念

机械能守恒只在“没有机械能与内能/电能等转化”时成立；能量守恒永远成立。

三能与机械能表达式 公式

先会算三能，才能谈守恒：动能、重力势能、弹性势能。

W_G = −ΔE_p 与 W_弹 = −ΔE_弹 公式

重力做多少正功，重力势能就减少多少；弹力做多少正功，弹性势能就减少多少。

判据式 W_其他 = ΔE_机 公式

判断守恒与否的唯一通用公式：算出重力（弹力）以外所有力的总功，看它是否为零。

表达一：E₁ = E₂（两状态） 公式

同一系统任意两个状态的机械能总量相等。

表达二：ΔE_k = −ΔE_p（两能量） 公式

同一系统内动能与势能此增彼减，增减量相等。

表达三：ΔE_A = −ΔE_B（两物体） 公式

系统内两个物体之间发生能量转移时，一个减少的机械能等于另一个增加的机械能。

单摆的几何与速度关系 公式

摆长与摆角决定释放高度，进而由能量守恒决定任意位置的速率。

v² = 2g(h₀ − h) 与 v²–h 直线 公式

由静止释放并只受重力支持力不做功时，v² 与 h 成线性关系，斜率 = −2g。

过山车的临界：h₀ ≥ 2.5R 公式

能“贴着轨道”通过竖直圆环最高点，需要 v² ≥ gR，对应释放高度 h₀ ≥ 2.5R。

内能增量 Q = f · Δs_相对 公式

系统机械能的损失等于产生的内能，量度用相对位移。

张力、支持力垂直速度 ⇒ 不做功 规律

单摆绳张力始终沿绳、圆环/斜面支持力始终垂直速度，做功恒为零，故不影响机械能。

有阻力时 −dE_机/dt = f·v 规律

机械能减少的快慢等于阻力做功的功率。

连接体：整体守恒、单体不守恒 规律

轻绳连接的两物体组成的系统机械能守恒；但张力对每个物体都做功，单个物体不守恒。

摆角不影响守恒，只影响运动性质 规律

任意摆角机械能都守恒；小角近似只关系到是否简谐、周期是否与振幅无关。

判据法：三步判断守恒 方法

一看受力与位移方向，二算各力做功，三看 W_其他 是否为零。

能量条法与三种表达的选取 方法

两状态用 E₁=E₂；系统内动势对改用 ΔE_k=−ΔE_p；两物体转移用 ΔE_A=−ΔE_B。

图象法：E_机–t 水平线 与 v²–h 直线 方法

水平的总能量线与直线的 v²–h 图是守恒的两个图象指纹。

光电门误差与修正 方法

光电门测的是“挡光过程的平均速度”，要用小挡光片 + 修正才能逼近瞬时速度。

守恒条件 vs 只受重力 / 合外力为零 / 匀速 辨析

条件是“只有重力（弹力）做功”，与受力多少、合力是否为零、是否匀速都无关。

三种表达的适用对象辨析 辨析

E₁=E₂ 看两状态、ΔE_k=−ΔE_p 看同一系统两能量、ΔE_A=−ΔE_B 看系统内两物体。

竖直弹簧振子的能量构成 辨析

竖直弹簧振子的机械能必须包含重力势能，三项之和才恒定。

能量足够 vs 动力学临界；摩擦力做功 vs 生热 辨析

“能量够”不等于“能沿轨道通过”；“摩擦力做的功”也不等于“摩擦生热”。
