历史逻辑时间轴：从伽利略到爱因斯坦

    逻辑链：伽利略相对性（力学）→ 麦克斯韦方程组预言电磁波速 c（相对"以太"）→ 迈克尔逊—莫雷实验零结果（测不到以太漂移）→ 爱因斯坦（1905）以相对性原理 + 光速不变原理两条假设重建时空观。洛伦兹、庞加莱已得到洛伦兹变换的数学形式，是重要前驱。光速不变是实验事实 + 原理选择，不是"光追不上"的直觉问题；现代物理不采用"以太真实存在"的表述。

    模块 B：光钟时间膨胀（几何推导）

    静止光钟（蓝）：光路竖直；运动光钟（橙）：光路斜向。由勾股定理 (cΔt/2)² = (cΔt₀/2)² + (vΔt/2)² 解得 Δt = γΔt₀。Δt₀ 为固有时（两事件同地，相对事件静止的钟测得）。钟慢是时空本身的性质——所有物理、化学、生物过程同步变慢；互为惯性系的双方都测得对方钟慢，并不矛盾（同时性不同）。

    模块 E：宇宙线 μ 子落地（钟慢效应数据验证，数据链闭合）

    μ 子静止平均寿命 τ₀ ≈ 2.2 μs。取 v = 0.998c ⇒ γ ≈ 15.8 ⇒ 实验室测得寿命 Δt = γτ₀ ≈ 34.8 μs ⇒ 射程 ≈ 10.4 km（与产生高度量级相符，故能到达地面）；经典预言仅约 660 m。等价解释：在 μ 子自身参考系中寿命不变（2.2 μs），是大气层厚度沿运动方向收缩为约 1/γ——两种解释自洽。

    模块 C：长度收缩（尺缩效应，"同时测量"可视化）

    L = L₀/γ：L₀ 为固有长度（物体静止系中测得），L 为相对物体运动的惯性系沿运动方向测得的长度。测量必须同时记录两端位置（依赖同时的相对性）；垂直方向不收缩。收缩是测量结果，不等于"眼睛看到的样子"（视觉效应含光传播延迟与光行差，即 Terrell 旋转——拓展）。

    模块 D：爱因斯坦火车 —— 同时的相对性

    地面观察者位于两事件中点：两道闪电同时击中列车前后端（地面系同时异地事件）。列车观察者位于车中点，向前进方向运动，先看到前端的光；扣除光传播时间后判定：两事件不同时（前端事件先发生）。区分"看到（光到达眼睛）"与"判定（扣除光传播时间）"。

    模块 F1：质能计算台（以静止质量 m₀ 为主线）

    动量 p = γm₀v，总能量 E = γm₀c²，静止能量 E₀ = m₀c²，动能 E_k = (γ−1)m₀c²。旧表述"质量随速度增大"即相对论质量 m = γm₀（此时 E = mc²）；现代物理更倾向只用不变质量 m₀，避免"质量随速度变"的误解。E = mc² 应理解为质量与能量等价（质量是能量的一种量度），核反应中质量亏损对应释放能量 ΔE = Δm·c²；不能说"质量变成了能量"。β→1 时 γ→∞，所需能量→∞，有质量物体不能达到光速；无质量粒子（光子）只能以 c 运动。

    模块 F2：相对论速度叠加 vs 伽利略叠加

    一维速度变换 u = (u′+v)/(1+u′v/c²)。u′=c 时 u=c（光速不变）；两个 0.9c 合成仍小于 c（u ≈ 0.994c）。低速下与伽利略叠加 u = u′+v 一致。超光速信号会破坏因果顺序（类空间隔事件的时序可反转）——拓展。

    模块 G：牛顿力学适用域地图（对数坐标）+ 对象探针

    横轴：速度（对数，β = v/c）；纵轴：尺度（对数，m）。牛顿力学适用于宏观、低速（v≪c）、弱引力场。高速→狭义相对论；微观（作用量 ~ h）→量子力学；强引力场→广义相对论。拖动探针或点击预设对象，实时显示应使用的理论。

    结论总结

    两大基本假设（相对性原理 + 光速不变原理）⇒ 洛伦兹变换 ⇒ γ = 1/√(1−β²) ⇒ Δt = γΔt₀（钟慢）、L = L₀/γ（尺缩）、Δt′ = −γvΔx/c²（同时的相对性）、E = γm₀c² 与 E₀ = m₀c²（质能等价）。牛顿力学适用于宏观、低速、弱引力；v≪c 时相对论退化为牛顿力学（对应原理）——扩展而非推翻。
