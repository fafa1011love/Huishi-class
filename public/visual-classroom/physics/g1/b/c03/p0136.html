本模型核心结论速查

v₁ = √(GM/R) ≈ 7.9 km/s（最小发射速度＝近地最大环绕速度）
v₂ = √2·v₁ ≈ 11.2 km/s（脱离地球，E = 0）
v₃ = √(12.3² + 11.2²) ≈ 16.7 km/s（脱离太阳）
v = √(GM/r)、T = 2π√(r³/GM)（仅圆轨道）
r_同 = ∛(GMT²/4π²) ≈ 4.22×10⁷ m，h ≈ 3.58×10⁷ m，v ≈ 3.07 km/s
加速 ⇒ 离心抬升；稳定后新圆轨道速度更小
安全与规范提示：本模型的理想化假设（点击展开）
① 本模型为理想二体仿真：运动方程 r̈ = −GM·r̂/r²，只考虑中心天体一个引力源，忽略大气阻力（可手动开启）、地球非球形（J₂ 摄动）、日月与行星引力摄动、太阳光压与相对论效应。
② “三个宇宙速度”以从地表发射、不计空气阻力、不计地球自转为前提；实际火箭因克服重力损失与气动阻力需要更大的速度增量，而在赤道向东发射可利用地球自转约省 0.46 km/s。
③ 圆轨道与同步卫星优先使用解析解（v = √(GM/r)、T = 2π√(r³/GM)），椭圆/逃逸轨道使用固定步长速度 Verlet 积分（含子步细分），实时显示 E、L 的守恒误差（典型 < 0.01%）。
④ 落回判定：近地点 r_p ≤ R（可选含 100 km 大气层阈值）时停止积分并标注落点与射程，不允许穿地；逃逸判定：E ≥ 0 时标记抛物线/双曲线，并注明开普勒椭圆定律形式不适用。
⑤ 月球一行按“地球 GM 二体”计算（忽略月球质量 1/81），T 与真实恒星月 27.32 d 相差约 0.5%；v₃ 相关说明以卡片呈现，未做日心系三体完整仿真。
