本实验知识卡片

1实验装置与研究对象

注水密封玻璃管中放入蜡块，蜡块相对水匀速上浮；同时使管沿水平方向运动。
研究对象是蜡块相对地面（黑板）的运动，即合运动；管水平运动与蜡块沿管上浮是两个分运动。

2分运动与合运动的三条性质

  • 等时性：分运动与合运动同时开始、同时结束，时间相同
  • 独立性：各分运动互不影响，可单独研究（改变 vy 不影响水平运动）
  • 等效性：合运动与分运动共同产生的效果完全相同

3位移的合成

两分位移互相垂直时：s = √(x² + y²)，tanθ = y/x（θ 为 s 与水平方向夹角）。
本实验中 x = vxt、y = vyt。

4速度的合成

遵循平行四边形定则（矢量相加）：v = √(vx² + vy²)，tanθ = vy/vx。
合速度可以大于、等于或小于任一分速度，取决于两分速度的夹角。

5匀速 + 匀速 → 直线运动

两方向都匀速时，消去 t 得轨迹方程 y = (vy/vx)x，是过原点的直线，斜率 k = vy/vx。
频闪点等间距分布，相邻点 Δx、Δy 恒定。

6匀速 + 匀变速 → 曲线运动

水平匀变速、竖直匀速时轨迹为抛物线（类平抛）。
判据：合加速度（合力）与合速度不共线 → 曲线运动；轨迹向合力一侧弯曲，合力指向凹侧。

7频闪照片的数据处理

闪光间隔 Δt 相同，故 Δx = vxΔt、Δy = vyΔt；
由 vy = Δy/Δt 求速度，用逐差法 a = (x₄+x₅+x₆−x₁−x₂−x₃)/(9Δt²) 求加速度。
改变 Δt 后旧点保留，点疏密变化即体现新间隔。

8位置回溯与易错点

量筒位置 X(t) 与查询位置画横线，交点即“经过时刻”；折返时 vx=0，是 X–t 图线的顶点（相切交点）。
易错：① 同一位置两次经过，速度方向相反；② 分运动改变不影响另一分运动；③ 速度方向沿轨迹切线，不是位移方向。
