拓展 · 进阶层 曲率与法向力（定性）

一般曲线运动中，把合力沿切向和法向分解：

Ft = m·at   （只改变速率）
Fn = m·v²/ρ   （只改变方向，ρ 为曲率半径）

等速率通过时：曲率越大（ρ 越小，弯得越急），需要的法向力越大；v 越大，需要的法向力也越大（与 v² 成正比）。

本模型对 F_n、ρ 只作定性提示，不做定量要求。

设计说明 · 验收清单（点击展开）

一、两套物理模型严格区分

  • 俯视（水平桌面）：重力被支持力平衡，轨道在水平面内，速度大小恒定；合外力只由轨道侧向弹力提供，是纯法向力 m·v²/ρ。小球飞出后无侧向力 → 沿出口切线做匀速直线运动。
  • 侧视（竖直平面）：轨道在竖直平面内，合力 = 重力 + 轨道弹力 = m·at·t̂ + m·v²/ρ·n̂。小球飞出后只受重力 → 抛体运动，但初速度方向仍是出口切线。
  • 两种情境下受力箭头、文字说明、飞行轨迹全部不同，不混用。

二、几何与数值

  • 轨道用解析参数曲线描述（圆弧/抛物线/椭圆弧/双圆弧 S 形/三点二次贝塞尔），切线由解析一阶导数求得，曲率由一阶、二阶导数按 κ=(x′y″−y′x″)/|p′|³ 求得，不做像素差分。
  • 按弧长重参数化，固定步长 dt = 1/240 s 积分，不同帧率下结果完全一致。
  • v₀ 的含义随视角而变，且真实生效：俯视时水平面内没有切向力、轨道弹力不做功，v₀ 就是全程恒定速率（严格处处相等，不是“初”速度），改它只改变快慢、不改变轨迹；侧视时 v₀ 是真正的释放点初速度，之后速率由能量守恒 v² = v₀² + 2g(h₀ − h) 给出，v₀ 过小时小球到不了出口，会沿轨道滑回并停住。实时读数、探针读数、静态分帧、主积分全部调用同一个速率函数，不会出现“读数一个值、动画另一个值”。
  • 出口角滑块把整条轨道绕出口点旋转，使末端解析切线角精确等于设定值；出口点固定在原点，因此多次实验的飞出直线从同一点发出，便于逐一比对。
  • “出口切线角”取自末端解析切向量；“飞出方向角”取自飞出瞬间的速度矢量（vx、vy，由受约束运动积分得到，与切线公式相互独立）。两者吻合即为“瞬时速度沿切线”的数值证据，显示精度下差值恒为 0.0°。
  • 侧视时另设“当前速度偏离切线”一栏：飞出瞬间为 0°，随后因重力持续增大——这正是“抛体运动的初速度沿切线，之后方向不断改变”的直观体现。

四、验收清单

  • 瞬时速度沿切线：探针工具提示中“切线角 θ”与“速度方向”完全一致（同一单位向量），蓝色速度箭头与黑色轨迹切线段共线。
  • 飞出方向即出口切线：记录表“差值”列恒为 0.0°（平均 < 1e-12，仅在显示精度内为 0）。
  • 合力指向凹侧：红色合力箭头恒在蓝色半透明凹侧阴影内；数据面板“v 与 F 夹角”< 90° 时速率增大、> 90° 时减小、= 90° 时不变。
  • 合力反向则弯曲反向：点“合力反向 → 弯曲反向”，轨迹向原理弯曲方向的反侧弯曲，并弹出红色纠错。
  • 曲线运动必有加速度：任何取点处 F_n = m·v²/ρ ≠ 0（ρ 有限），轨迹切线角 θ–t 曲线随时间单调（或持续）变化，速度方向一直在变。
  • 撤去侧向力：任意点撤去后沿该点切线做直线运动，速率读数在俯视模型下保持常数。
  • 仅凭墨水印迹：关闭全部辅助图层后，仍能看到“轨道墨迹”与“飞出直线墨迹”在出口处光滑相切。

五、自测步骤

  • ① 出口角设为 30°，播放到飞出 → 读出“飞出方向角”与“出口切线角”，差值应 ≤ 0.1°（验收线 0.5°）。
  • ② 在轨迹上点三处取探针 → 蓝色速度箭头始终指向运动一侧，红色合力箭头始终落在凹侧阴影内。
  • ③ 选“指向凸侧（错误示范）” → 轨迹朝凸侧反向弯曲，顶部弹出红色纠错说明；改回“指向凹侧（正确）”后恢复相切直线。
